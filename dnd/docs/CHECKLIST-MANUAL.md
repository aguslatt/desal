# Checklist manual de accesibilidad

Probar con **VoiceOver** (iOS/macOS), **TalkBack** (Android) y **NVDA** (Windows).
Marcá cada ítem por lector. Se agregan ítems al cerrar cada fase.

## Fase 1: base, modos de visualización, datos

| # | Qué probar | VO | TB | NVDA |
|---|---|---|---|---|
| 1 | Al abrir, el lector dice el idioma español y el título de la página | ☐ | ☐ | ☐ |
| 2 | Primer Tab: "Ir al contenido". Con Enter, el foco salta al contenido principal | ☐ | ☐ | ☐ |
| 3 | El banner "Datos de demostración" se lee antes del encabezado | ☐ | ☐ | ☐ |
| 4 | Landmarks: banner, navegación "Principal", principal, pie. Hay un solo h1 por página | ☐ | ☐ | ☐ |
| 5 | "Visualización": el botón dice si está expandido o contraído; Escape lo cierra y devuelve el foco | ☐ | ☐ | ☐ |
| 6 | Cada grupo de opciones (tamaño, tema) se anuncia con su nombre y la opción elegida | ☐ | ☐ | ☐ |
| 7 | Los interruptores (alto contraste, reducir movimiento, lectura fácil) dicen si están activados | ☐ | ☐ | ☐ |
| 8 | Los estados se leen como texto ("Confirmado", "No disponible", "Sin información"); los íconos no se leen | ☐ | ☐ | ☐ |
| 9 | Con texto "Enorme" no hay scroll horizontal y nada se corta | ☐ | ☐ | ☐ |
| 10 | Con zoom del navegador al 400 % no hay scroll horizontal | ☐ | ☐ | ☐ |
| 11 | Modo oscuro y alto contraste: todo se lee y el foco se ve | ☐ | ☐ | ☐ |
| 12 | Con "reducir movimiento" no hay animaciones | ☐ | ☐ | ☐ |

## Fase 2: necesidades, listado, mapa, ficha

| # | Qué probar | VO | TB | NVDA |
|---|---|---|---|---|
| 13 | "Mis necesidades": cada condición se anuncia como casilla con su nombre y si está marcada; cada dimensión como grupo | ☐ | ☐ | ☐ |
| 14 | Al marcar una condición se anuncia "N condiciones marcadas" | ☐ | ☐ | ☐ |
| 15 | Listado: al cambiar rubro, barrio o condiciones se anuncia "N lugares cumplen tus condiciones" | ☐ | ☐ | ☐ |
| 16 | Cada tarjeta lee: rubro y barrio, nombre (encabezado), "Cumple N de M", y el estado de cada condición con texto | ☐ | ☐ | ☐ |
| 17 | El lugar patrocinado se anuncia como "Patrocinado" | ☐ | ☐ | ☐ |
| 18 | Los botones Listado/Mapa dicen si están presionados | ☐ | ☐ | ☐ |
| 19 | Mapa: Tab llega a cada marcador y lee nombre y coincidencia; Enter abre el resumen y mueve el foco a "Ver ficha"; Escape lo cierra y vuelve al marcador | ☐ | ☐ | ☐ |
| 20 | El texto sobre el mapa dice que el listado tiene la misma información y ofrece volver al listado | ☐ | ☐ | ☐ |
| 21 | Ficha: un solo h1; "Tus condiciones" arriba, con estado, fuente y fecha de cada dato | ☐ | ☐ | ☐ |
| 22 | Secciones desplegables: el botón dice "expandido/contraído" y el resumen de la sección | ☐ | ☐ | ☐ |
| 23 | Bodegón El Retoño Gris: el aviso de discrepancia se lee antes de "Tus condiciones" | ☐ | ☐ | ☐ |
| 24 | "Guardar" dice si está presionado | ☐ | ☐ | ☐ |

## Fase 3: reporte, recorrido, momentos tranquilos

| # | Qué probar | VO | TB | NVDA |
|---|---|---|---|---|
| 25 | Reporte: al avanzar, el lector dice la pregunta nueva (el foco pasa al título) y "Pregunta N de 9" | ☐ | ☐ | ☐ |
| 26 | Cada pregunta se anuncia como grupo con sus 4 opciones (Sí / No / No lo sé / No aplica) y cuál está elegida | ☐ | ☐ | ☐ |
| 27 | Si seguís sin responder, el error se lee solo: "Elegí una opción para seguir." | ☐ | ☐ | ☐ |
| 28 | "¿Encontraste algo diferente?" = Sí: el campo "Contanos qué encontraste distinto" se anuncia como obligatorio con su error | ☐ | ☐ | ☐ |
| 29 | Foto: un archivo que no es imagen o pesa más de 5 MB muestra el error en texto | ☐ | ☐ | ☐ |
| 30 | Resumen: cada "Cambiar" dice qué pregunta cambia | ☐ | ☐ | ☐ |
| 31 | Confirmación: se lee "¡Gracias! Recibimos tu reporte" | ☐ | ☐ | ☐ |
| 32 | Recorrido: "Paso N de 5: título" se anuncia al avanzar, y cada foto lee su descripción | ☐ | ☐ | ☐ |
| 33 | Recorrido: "Ver todo el recorrido como texto" muestra los 5 pasos seguidos | ☐ | ☐ | ☐ |
| 34 | Momentos tranquilos: el lector lee la tabla (franja, ruido, concurrencia) y no repite el gráfico | ☐ | ☐ | ☐ |
